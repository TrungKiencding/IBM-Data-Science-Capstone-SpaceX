# IBM Applied Data Science Capstone – SpaceX Falcon 9 Landing Prediction

Predict whether the Falcon 9 first stage lands successfully, to estimate launch cost for a competitor.

| # | Notebook / file | Content |
|---|---|---|
| 1 | `1_jupyter-labs-spacex-data-collection-api.ipynb` | Data collection – SpaceX REST API |
| 2 | `2_jupyter-labs-webscraping.ipynb` | Data collection – Wikipedia web scraping |
| 3 | `3_labs-jupyter-spacex-Data-wrangling.ipynb` | Data wrangling, `Class` label |
| 4 | `4_jupyter-labs-eda-sql-coursera_sqllite.ipynb` | EDA with SQL |
| 5 | `5_edadataviz.ipynb` | EDA with visualization, feature engineering |
| 6 | `6_lab_jupyter_launch_site_location.ipynb` | Interactive map with Folium |
| 7 | `spacex_dash_app.py` | Plotly Dash dashboard |
| 8 | `7_SpaceX_Machine_Learning_Prediction_Part_5.ipynb` | Classification (LR, SVM, Tree, KNN) |
| – | `SpaceX_Capstone_Report.pdf` | Final presentation |

Results: overall landing success 67%; KSC LC-39A best site (76.9%); Decision Tree best CV accuracy (87.7%), test accuracy 83.3%.
